How to Use This Page

  1. Pick a module tab based on the analysis you want.
  2. Use Autofill if you want quick sample values, or enter your own values.
  3. Enter realistic numbers only. Keep percentages between 0 and 100 where mentioned.
  4. Click the module button to run prediction and read the result, insight, and policy tips.
